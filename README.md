## Описание и проблема
В колледже информация об оборудовании ведётся на бумаге и может теряться.
При уходе или увольнении ответственного лица теряются знания о том, где
находится конкретное оборудование.

**Проблема:** невозможно быстро определить местоположение устройства;
неизвестно, какая аппаратура рабочая, какая требует настройки или починки;
отсутствует нормальная среда для быстрой проверки наличия и
работоспособности техники.

### Поля записи

| Поле | Обязательное | Тип | Пример | Правило заполнения |
|---|---|---|---|---|
| `inventory_number` | ✅ | строка | `INV-2024-00157` | Уникален среди активных карточек |
| `type` | ✅ | строка | `Монитор` | Тип оборудования |
| `name` | ✅ | строка | `Dell P2422H (24", IPS)` | Однозначно идентифицирует объект |
| `room` | ✅ | строка | `Каб. 312 (Отдел разработки)` | Совпадает с фактическим местом |
| `state` | ✅ | строка | `Требует ремонта` | Только из допустимых значений |
| `comment` | ⛔ | строка | `Не работает подсветка` | Уточнение к состоянию |
| `responsible` | ⛔ | строка | `Иванов И. И. (инженер)` | Конкретное физлицо |
| `received_at` | ⛔ | строка (ISO) | `2024-09-01` | Дата поступления |
