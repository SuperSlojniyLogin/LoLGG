# Система учёта компьютерного оборудования колледжа

Учебная практика 2026 Проект **LoLGG**

## Цель проекта
Создать работоспособное приложение на Python для учёта компьютерного
оборудования, его работоспособности и конкретного нахождения.

## Содержание

#### Формат хранения данных
**База данных — JSON-файл** `data/inventory.json`. Это массив объектов.
Каждая запись — карточка оборудования.


## Описание и проблема
В колледже информация об оборудовании ведётся на бумаге и может теряться.
При уходе или увольнении ответственного лица теряются знания о том, где
находится конкретное оборудование.

**Проблема:** невозможно быстро определить местоположение устройства;
неизвестно, какая аппаратура рабочая, какая требует настройки или починки;
отсутствует нормальная среда для быстрой проверки наличия и
работоспособности техники.

## Инструкция как пользоваться нашим приложением
#### Допустимые значения для `state`
- `Исправно`
- `Требует ремонта`
- `Списано`
